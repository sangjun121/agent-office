일할 곳

보고받을 앱 고르기

이 Mac에서 찾은 앱 가운데 보고받을 앱만 켜 두세요.

앱을 찾고 있어요
  • 로그인이나 API 키 없이, 각 앱이 이 Mac에 남긴 작업 기록만 읽어요.
  • ChatGPT 앱과 Claude 앱의 일반 채팅은 작업 기록이 남지 않아서 볼 수 없어요. Claude 앱의 Code 탭에서 맡긴 일은 위의 Claude에 나와요.

알림 설정

작업실 창을 닫아 둬도, 일이 끝나면 알림으로 알려 줘요.

사용법

파일  편집  보기 2 🔋 9:41
에이전트 작업실25
  1. 상단바의 말풍선 아이콘을 누르면 작은 작업실이 펼쳐져요.
  2. 아이콘 옆 숫자는 아직 읽지 않은 보고 수예요.
  3. 작은 창의 핀 버튼을 누르면 다른 곳을 눌러도 닫히지 않아요.
  4. 아이콘을 오른쪽 클릭하면 크게 보기, 연동 설정, 튜토리얼 다시 보기가 나와요.
상단바에 아이콘이 보이지 않을 때

상단바에 아이콘이 많으면 새로 생긴 아이콘이 노치나 메뉴 뒤로 가려질 수 있어요.

  1. 바로 열기⌘ Space로 Spotlight를 열고 Agent Office를 실행하면 작업실 창이 떠요. 보고 알림을 눌러도 열려요.
  2. 자리 만들기시스템 설정 → 메뉴 막대에서 안 쓰는 항목을 끄면 자리가 생겨요. macOS 15 이하에서는 시스템 설정 → 제어 센터에서 꺼요.
  3. 자리 옮기기⌘ 키를 누른 채 아이콘을 시계 쪽으로 끌어다 놓으면, 다음에 켜도 그 자리에 떠요.
