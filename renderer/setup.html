이 Mac에서 찾은 앱이에요.

찾는 중…
  • 로그인이나 키는 필요 없어요.
    각 앱이 이 Mac에 남긴 작업 기록만 읽어요.
  • ChatGPT, Claude 앱의 일반 채팅은 볼 수 없어요.
    Claude 앱의 Code 탭은 위의 Claude로 보여요.

에이전트 작업실🛠 2✅ 5
  1. 상단바 말풍선을 눌러요작은 작업실이 펼쳐져요
  2. 숫자가 뜨면 보고가 온 거예요일이 끝날 때마다 하나씩 늘어요
  3. 핀 버튼을 누르면 고정돼요다른 곳을 눌러도 안 닫혀요
  4. 오른쪽 클릭하면 메뉴가 나와요크게 보기, 설정, 튜토리얼 다시 보기
상단바에 아이콘이 안 보이나요?

아이콘이 많으면 새 아이콘이 노치나 메뉴 뒤로 숨을 수 있어요.

  1. 바로 열기⌘ Space를 누르고 Agent Office를 실행해요.
    보고 알림을 눌러도 열려요.
  2. 자리 만들기시스템 설정 → 메뉴 막대에서 안 쓰는 항목을 꺼요.
    macOS 15 이하는 시스템 설정 → 제어 센터예요.
  3. 자리 옮기기⌘ 키를 누른 채 아이콘을 시계 쪽으로 끌어요.
    다음에 켜도 그 자리에 떠요.
